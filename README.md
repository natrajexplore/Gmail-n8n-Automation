# Gmail-n8n-Automation
Gmail Automation
An n8n AI-powered Gmail automation that lets a user interact with an AI Agent through the n8n chat interface and send emails through Gmail using natural-language instructions.

How It Works
1. Chat Trigger
The When chat message received node starts the workflow when a user sends a message through the n8n chat interface.

Example:

Send an email to john@example.com with the subject Meeting and tell John that the meeting is confirmed.
2. AI Agent
The AI Agent is the main controller. It interprets the user's request and can use the connected Gmail tool.

For an email request, it can determine:

Recipient

Subject

Message

3. Brain — OpenAI
The Brain node supplies the language model used by the AI Agent.

Current model:

gpt-4.1-mini
4. Memory
The Memory node provides conversational context to the AI Agent.

For example:

User: Send an email to Sarah saying the project is ready.

User: Make it more professional.
Memory can help the agent understand that the second request refers to the previous email.

5. Gmail Action
The Action node is the Gmail tool connected to the AI Agent.

It uses AI-generated values for:

To
Subject
Message
The Gmail OAuth2 credential authorizes the account that sends the email.

Example Requests
Simple email
Send an email to alice@example.com with the subject Hello and say Hope you're doing well.

Email john@example.com and tell him that our meeting is confirmed for Monday at 10 AM.

gpt-4.1-mini

Configure a Gmail OAuth2 credential and authorize the Google account that should send emails.

Gmail OAuth Setup
For self-hosted n8n, the Google OAuth redirect URI must exactly match the callback URL shown by the n8n Gmail credential.

Basic setup:

Open the Gmail credential in n8n.

Copy the OAuth Redirect URL shown by n8n.

Open Google Cloud Console.

Go to APIs & Services → Credentials.

Open the OAuth 2.0 Client ID used by n8n.

Confirm it is a Web application client.

Add the exact n8n callback URL under Authorized redirect URIs.

Save the Google OAuth client.

Return to n8n.

Click Sign in with Google and authorize the account.

Do not manually change the callback URL.

Importing the Workflow
Open your n8n instance.

Go to Workflows.

Select Import from File.

Select Gmail Automation.json.

Review the OpenAI credential.

Review the Gmail OAuth2 credential.

Save the workflow.

Test it using the n8n chat interface.

Activate the workflow after successful testing.

Troubleshooting
AI Agent does not send an email
Check:

Gmail credential is connected.

Gmail Action is connected to the AI Agent as an AI tool.

The request explicitly asks to send an email.

The recipient address is valid.

The Gmail account is authorized.

redirect_uri_mismatch
The redirect URI configured in Google Cloud does not exactly match the URL generated by n8n.

Copy the URL directly from the n8n Gmail credential and add it to Google's Authorized redirect URIs.

Gmail authorization fails
Check:

OAuth Client ID and Client Secret

OAuth client type

Redirect URI

Google OAuth consent configuration

Gmail API access

Authorized/test users

AI misunderstands the request
Be explicit:

Send an email to john@example.com with the subject Project Update and tell him that the project is ready.
Safety Recommendations
Because this workflow can send real emails, test it carefully before production use.

Recommended improvements:

Require confirmation before sending important emails.

Add an approval step for external recipients.

Log email requests and results.

Avoid automatically sending sensitive information.

Consider using a dedicated Gmail account for automation.

Never expose API keys, OAuth secrets, refresh tokens, or access tokens.
